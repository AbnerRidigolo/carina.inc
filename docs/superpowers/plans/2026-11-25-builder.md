# Builder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Estratégias declarativas (`buy_hold`, `sma_cross`) por tenant e backtest determinístico sem lookahead sobre o histórico de mercado, cobrado como `backtest`.

**Architecture:** Módulo `apps/api/src/modules/builder` com o motor puro (`runBacktest`), um repositório sob RLS (tabela `strategy`, migração 0010) e um controller com quatro rotas; contratos em `packages/shared/src/builder.ts`.

**Tech Stack:** NestJS 12 ESM, Prisma 7 com RLS, Zod 4, Vitest unit/int/e2e.

**Spec:** `docs/superpowers/specs/2026-11-25-builder-design.md`

## Global Constraints

- Fonte: `legacy/python/carina/builder/{strategies,backtest}.py`, `legacy/python/tests/test_builder.py`, rotas `/builder/*` em `legacy/python/carina/api/routes.py`. A matemática do backtest é a do Python, número a número.
- `fast` 2..200, `slow` 3..400, `fast < slow` só em `sma_cross` (padrões 10 e 50); `name` 1..120; até **100** estratégias por tenant.
- `range` ∈ `HistoryRangeSchema`, padrão `1y`; mínimo de barras 2 (`buy_hold`) ou `slow + 1` (`sma_cross`).
- Métricas arredondadas a 4 casas como o `round` do Python; volatilidade com desvio-padrão populacional × √252.
- Escopo novo `builder:run` (o seed o dá à chave de demo com `data:write`). Criar/listar/ler sem cobrança; backtest reserva a cota mensal, cobra `backtest` só no sucesso e estorna a cota se a cobrança falhar.
- Logs só com ids, `kind` e contagens.
- Antes de cada commit: `pnpm lint` (ESLint limpo; sem `!`), `pnpm typecheck`, `pnpm test` (o teste de estouro de memória de `parse-file.spec.ts` falha só localmente pelo Node 22.23.4; ignorar só esse); Tasks 2–3 também `test:int` e `test:e2e` da API nos dois locales (Postgres + Redis locais).
- Português em textos, comentários, testes e commits.

## Review Focus

1. **Lookahead**: o sinal que nasce no fechamento do dia `t` só afeta o retorno de `t+1`. → Task 1.
2. **Histórico com barras de preço igual** (retorno zero) e **série de 2 barras**: sem divisão por zero, volatilidade 0 quando há um retorno só. → Task 1.
3. **Estratégia de outro tenant** no GET e no backtest → 404, sem cobrança. → Task 3.
4. **Provedor fora / orçamento esgotado / símbolo desconhecido** no backtest → erro sem cobrança e com a cota estornada. → Task 3.
5. **101ª estratégia** → 422. → Task 2.
